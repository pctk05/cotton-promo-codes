## Where do you enter a Cotton On promo code?

Cotton On takes promo codes in one specific spot: the **"Promo Code / Perks Voucher" box** on your bag page or at checkout. It's easy to miss because it sits below your items, next to the delivery options — not at the top of the page.

The full flow:

1. Add your items using the "Add To Bag" button.
2. Click the shopping bag icon in the top right corner to open your "MY BAG" page.
3. Scroll down past your items. In the grey box to the right, under the delivery options, you'll see the white "Promo Code / Perks Voucher" field. Type your code and hit the black "Apply" button.
4. Check the Bag Summary total before pressing "CHECKOUT NOW".

Two details worth knowing before you type anything. First, Cotton On promo codes are **case sensitive**, so copy them exactly as written. Second, always confirm the discount actually shows up in the Bag Summary after you tap Apply — if the total doesn't move, the code didn't take, and paying anyway means losing the discount.

## Why your Cotton On promo code isn't working

A rejected code almost always comes down to one of a handful of known causes, and Cotton On's own help docs spell most of them out. Going through the list in order saves a lot of guessing:

- **The code has already been used.** Cotton On promo codes can only be used once. If you (or the Perks account the code was issued to) already applied it, it's dead.
- **Your bag has sale items in it.** The Perks first-order 20% offer applies to full-price items only, so a bag full of sale stock won't qualify.
- **The code was issued to a different Perks account, or it expired.** Many codes are account-specific rather than public.
- **Your items are already in a multi-buy deal.** Tops at 2 for $30 are already discounted, and codes generally won't combine with that pricing.
- **The code is for a different Cotton On country store.** A code from the Australian site won't work on the US site, and vice versa.
- **A typo or stray space.** Boring, but it happens — especially with case-sensitive codes.

If you've ruled all of those out and the code still fails, it's usually simpler to lean on the no-code discounts below, which apply automatically.
